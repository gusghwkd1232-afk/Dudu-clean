두두 클린 청소용품 카탈로그 (샘플)

- index.html: 완성된 단일 파일 웹사이트. CSS/JavaScript/샘플 제품 10개가 내장되어 있습니다.
- products.csv: 샘플 제품 목록 참고용 파일입니다. 현재 웹페이지는 index.html 안의 샘플 데이터를 사용합니다.
- 모든 상품은 예시 데이터이며 실제 상품명/규격/사진으로 교체해 주세요.
- 문의 버튼은 기기의 기본 이메일 앱을 열지만, 받는 이메일 주소는 설정하지 않았으므로 실제 회사 이메일 주소를 연결해야 합니다.

Cloudflare 업로드 시:
1) ZIP을 그대로 올리지 말고 압축을 풉니다.
2) index.html이 최상위에 오도록 파일을 업로드합니다.
3) 배포 후 사이트 주소를 열어 검색, 카테고리, 상세 보기 기능을 확인합니다.
