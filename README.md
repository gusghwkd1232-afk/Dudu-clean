# 청소용품 카탈로그

가격 비공개, 제품 문의 중심의 정적 카탈로그 사이트입니다. HTML/CSS/JavaScript와 CSV 파일을 사용하며 별도 데이터베이스는 필요하지 않습니다.

## 폴더 구조

```text
cleaning-catalog/
├── index.html
├── products.csv
├── assets/
│   ├── app.js
│   ├── config.js
│   └── style.css
├── images/
│   └── placeholder.svg
└── README.md
```

## 로컬에서 실행하기

`index.html`을 파일 탐색기에서 직접 열면 브라우저 보안 정책 때문에 CSV 파일을 불러오지 못할 수 있습니다. 간단한 로컬 웹 서버로 실행하세요.

### Python이 설치되어 있는 경우

터미널/명령 프롬프트에서 프로젝트 폴더로 이동한 다음:

```bash
python -m http.server 8000
```

Windows에서 `python` 명령이 동작하지 않으면 다음을 시도하세요.

```bash
py -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

## 회사 정보 및 문의처 설정

`assets/config.js`를 열어 아래 항목을 실제 정보로 수정합니다.

- `companyName`: 회사명
- `tagline`: 사이트 설명
- `phone`: 전화번호
- `email`: 문의 이메일
- `kakaoUrl`: 카카오톡 채널 URL
- `pageSize`: 한 페이지에 표시할 제품 수
- `csvPath`: CSV 파일 경로

전화번호, 이메일, 카카오톡 URL은 실제 값을 확인한 뒤 입력하세요. 비워 두면 임의의 연락처가 표시되지 않습니다.

## 제품 CSV 관리

`products.csv`는 UTF-8 CSV 파일입니다. 첫 행의 헤더 이름은 그대로 유지하세요.

필드:

`product_id,name,category,brand,specification,package_unit,description,usage,image,keywords,status`

- `product_id`: 고유 제품 코드. 중복되지 않도록 관리합니다.
- `name`: 제품명
- `category`: 카테고리
- `brand`: 브랜드/제조사
- `specification`: 규격·용량
- `package_unit`: 포장 단위
- `description`: 짧은 설명
- `usage`: 사용 용도
- `image`: 이미지 경로
- `keywords`: 추가 검색어. 여러 단어는 세미콜론으로 구분해도 됩니다.
- `status`: `active`만 표시됩니다. `inactive`는 목록에서 숨깁니다.

샘플 제품은 테스트용 가상 데이터입니다. 실제 판매 제품의 정보와 사진으로 교체하세요. `CL-0008`은 `inactive` 처리되어 사이트에 표시되지 않습니다.

### 제품 추가

1. CSV 마지막 행에 새 제품 행을 추가합니다.
2. 중복되지 않는 제품 코드를 부여합니다.
3. 제품 사진을 `images` 폴더에 넣습니다.
4. `image` 필드에 `images/제품코드.webp`처럼 경로를 입력합니다.
5. `status`를 `active`로 설정합니다.

### 제품 수정

CSV에서 해당 제품 코드의 행을 수정하고 저장합니다. 제품 코드는 유지하는 편이 좋습니다.

### 제품 삭제/비공개

완전히 지우기보다 `status`를 `inactive`로 변경하면 나중에 복구하기 쉽습니다. 행을 삭제해도 되지만, 과거 문의에서 사용한 제품 코드를 추적하기 어렵습니다.

### CSV 주의사항

- Excel에서 저장할 때 CSV UTF-8 형식을 선택하세요.
- 셀 안에 쉼표가 포함되면 CSV 프로그램이 해당 셀을 큰따옴표로 감싸도록 저장해야 합니다.
- `product_id`와 `name`이 없거나 제품 코드가 중복되면 사이트에서 정상적으로 표시되지 않을 수 있습니다.
- 고객에게 공개하면 안 되는 공급 단가, 매입 가격, 거래처별 가격은 CSV에 넣지 마세요.

## 이미지 관리

- 실제 판매 제품과 일치하는 사진만 사용하세요.
- 파일명은 제품 코드 기준으로 통일하면 관리하기 쉽습니다.
- 이미지가 없거나 로딩에 실패하면 `images/placeholder.svg`가 표시됩니다.
- 가능한 경우 이미지 크기를 줄이고 WebP 형식으로 저장합니다.
- 제조사/공급사 이미지의 사용 권한을 확인하세요.

## GitHub 및 Cloudflare Pages 배포

1. GitHub에 로그인하고 새 저장소(repository)를 만듭니다.
2. 이 폴더의 파일과 폴더를 저장소에 업로드합니다.
3. Cloudflare에 로그인한 뒤 Workers & Pages 또는 Pages 메뉴에서 새 Pages 프로젝트를 만듭니다.
4. Git 저장소 연결을 선택하고 방금 만든 GitHub 저장소를 연결합니다.
5. 정적 HTML 사이트이므로 프레임워크는 `None` 또는 정적 사이트에 해당하는 설정을 선택합니다.
6. 빌드 명령은 필요하지 않으며, 빌드 출력 디렉터리는 저장소 루트(`/`)로 지정합니다. 화면에 따라 입력 방식이 다르면 `index.html`이 있는 폴더를 출력 디렉터리로 지정하세요.
7. 배포가 끝나면 Cloudflare가 제공하는 주소를 열어 제품 목록과 검색을 테스트합니다.
8. GitHub 파일을 수정하고 커밋하면 자동으로 다시 배포됩니다.

Cloudflare 대시보드의 메뉴 명칭은 변경될 수 있으므로 현재 화면의 안내를 확인하세요. 무료 플랜의 사용량 및 정책은 배포 전에 확인하는 것이 좋습니다.

## 개인정보 및 공개 범위

이 사이트는 공개 카탈로그입니다. 링크를 받은 사람만 접속하도록 보장하지 않습니다. 주소가 전달되면 다른 사람도 접근할 수 있습니다. 비밀번호나 거래처별 가격 보호가 필요하다면 별도의 접근 제어를 추가하세요.

Google Sheets를 나중에 연동할 경우 공개용 데이터만 노출해야 합니다. 비공개 스프레드시트 전체를 브라우저 코드에 인증 없이 연결하지 마세요.

## 문제 해결

- 제품 목록을 불러오지 못함: 로컬 서버로 실행했는지, `products.csv` 경로가 맞는지 확인합니다.
- 사진이 보이지 않음: `image` 경로와 파일 이름의 대소문자를 확인합니다.
- 제품이 나타나지 않음: `status`가 `active`인지, 제품 코드와 이름이 있는지 확인합니다.
- 연락처 버튼이 안내만 표시함: `assets/config.js`에 실제 연락처를 등록했는지 확인합니다.
